ICEY 作弊面板 · v0.7.2

这个文件夹里的东西就是全部内容。直接丢进游戏根目录(和 ICEY.exe 同级)即可生效。
不需要改游戏任何原文件;删掉就是完全卸载。

== 两种装法 ==
【推荐】双击「ICEY V4.exe」——图形界面,会自动找到游戏目录,点「安装」就行。
       想装到别处点「浏览…」自己选;卸载也在这个界面里(右边那个「卸载」按钮)。
【手动】把本文件夹内的 winhttp.dll / doorstop_config.ini / .doorstop_version / BepInEx
       整个复制到游戏根目录。删掉这四个就是完全卸载。

== 使用 ==
正常启动游戏,进游戏后按 F1 开关面板。
进游戏后按 F2 可以开关**游戏自带的官方调试面板**(见下面单独一节)。
(注意:网上说的"按 ` 键开调试菜单"是不对的,游戏里那个键没有绑定任何功能。)

面板顶部左侧有一个「开发」按钮:点亮才会显示实验内容(方块人 / 换角色 / 调试项);
正常模式下方块人、借骨架、MC 攻击会被自动关掉(免得卡片藏起来了你没法关)。

== F2:游戏自带的官方调试面板 ==
游戏里本来就藏着一套**开发者用的调试面板**,但正式版把它关掉了。
现在按 F2 就能打开,再按一次关掉。里面有:

  · GameSetting  —— Cheat On/Off、$+100、难度(Easy/Normal/Hard/Hell)、字幕开关、
                    血宫模式、全关卡、Open Level Select、重置增强、BGM/音效音量
  · PlayerAttr   —— Full HP(满血)、Kill All Enemies(秒杀全部敌人)、Kill yourself、HP-20
  · Save         —— AutoSave / AutoLoad / Save / Load / Delete
  · GameInfo     —— FPS、物理帧率、关卡时间、场景名、AI 状态
  · EnemyGen     —— 刷怪台:选怪、生成、测试、孤立、多次、移除
  · Camera / Filter / KeyRebind —— 相机、滤镜、按键重绑

说明:这是**游戏自己写好的界面**,我们只是把它被关掉的那部分重新打开,没有改动游戏文件。
第一次按 F2 会自动加载(日志里搜 [dbg] 能看到加载了哪些面板)。

== 面板卡片一览(11 张)==
战斗 / 玩家 / 敌人 / 资源与进度 / 世界与画面 / 存档与剧情 / 配色 / 文本 / 换角色 / 方块人 / 水印界面

== 配色替换(运行时换色,不碰游戏文件)==
面板「配色」卡片。贴图放在:
    BepInEx\config\player_skin\<预设名>\<贴图名>.png
贴图名必须是这 11 个之一(大小写一致):
    NewPlayerNormal / NewPlayerAtk / NewPlayerAtkHV / NewPlayerSpAtk / NewPlayerUnderAtk /
    NewPlayerAtkUpRising / NewPlayerAtk_Illum / NewPlayerNormal_Illum / NewPlayerSPAtk_Illum /
    NewPlayerAtkUpRising_Illum / PlayerFlash
本包已带一套预设:sakura(浅粉)。
用法:开「配色替换(开/关)」→ 用「配色预设」左右箭头切换 → 点右边「应用」。
某个动作第一次出现时可能还是原色,最多 2~8 秒会自己跟上。关掉开关即刻还原原色。
加新预设:在 player_skin 下新建子目录丢 PNG,再点「刷新预设列表」;换了 PNG 内容点「重新读取 PNG」。
「重新扫描材质」会把扫描结果写进 BepInEx\LogOutput.log(搜 [skin]),坏了方便排查。
说明:一张 2048×2048 的 PNG 解到显存约 16MB,11 张全用约 200MB —— 不用的时候把开关关掉就会释放。

== 动态配色(颜色随时间变幻)==
「配色」卡片 →「动态配色」。两种模式:彩虹循环(色相绕色环)/ 呼吸明暗;可调速度、饱和度、最暗亮度。
它和「配色替换」是叠加关系:贴图决定底子,动态配色让基调整体流动。关掉即还原。

== 文本替换(改界面/剧情文字,不碰游戏文件)==
「文本」卡片。启动后会自动把所有词条导出到:
    BepInEx\config\text_all.txt
要改的行拷进:
    BepInEx\config\text_override.txt
格式是一行一条:「术语」+ Tab + 「原文」+ Tab + 「新文本」;第三列留空 = 不替换。
改完点「重新读取替换表」→ 开「文本替换」→ 点「刷新界面文本」。
卡片里有「打开替换表(记事本)」「打开全量术语(记事本)」「打开配置文件夹」三个按钮,不用自己找路径。

== MC 方块人(开发者模式)==
点亮顶部「开发」→「方块人」卡片。
- 「方块人(换建模)」:把艾希藏起来,换成一个 MC 风格的方块小人;「原角色显示」可选"隐藏"或"原角色实体叠加"(后者能把剑和刀光叫回来)。
- 皮肤放在 BepInEx\config\player_skin\_blocky\skin.png(本包带的是艾利克斯);剑的物品贴图也在同目录
  (wooden/stone/iron/golden/diamond_sword.png)。
- 「手持物品」可切空手/各种剑;剑的角度、俯仰、偏航、前后偏移、长度都有滑块。
- 「MC 攻击方式」:加攻击冷却(默认 0.625 秒 = MC 剑手感),可调间隔。

== 换角色(开发者模式)==
「换角色」卡片:扫描场景里的其他骨架 → 选一个 →「套用选中骨架」(把主角 6~7 个槽位的骨架数据换成它的)。
注意:敌人的骨架只有部分动作与主角同名(最多 7/22),所以动作会残缺;「还原原骨架」随时一键回退。

== 判定帧(防反 / 闪击反击窗口)==
「战斗」卡片 →「判定」分组。两个滑块联动：
    · 防反窗口(秒)   0 ~ 10 秒
    · 防反窗口(帧)   0 ~ 6000 帧(按当前世界帧率换算)
原版判定窗口约 0.083 秒（≈5 帧 @60fps）：在"被打中的前一瞬"闪避即可触发闪击反击并吃掉这次伤害。
把窗口拉宽 = 更容易触发；拉太大会破坏手感，自己调。需要已解锁技能「闪击反击」才生效。
（实现方式：拦截 FlashStart() 之后把 _flashEndCount 顶大 —— 不修改游戏文件，可随时归零还原。）

== 状态水印(右上角)==
「水印界面」卡片。只列**已开启**的功能名,逐字渐变 + 右侧同色竖条,颜色缓慢流动。
可切英文(English)、调大小、让它把未开启项也灰着列出来。

== 界面主题 / 开发者模式 ==
「水印界面」卡片:
- 「深色渐变主题(关=最初主题)」:默认是**最初那套**;打开换成深色渐变卡片风。
- 「开发者模式(实验功能)」:等同顶部「开发」按钮。
滚轮:内容超出视口时可滚;方向不顺手时,开发者模式下点「滚轮反向」当场翻。

== 卸载 ==
双击「ICEY V4.exe」→ 点右边的「卸载」按钮(会先弹一个警告框)。
或者手动删掉根目录下的 winhttp.dll、doorstop_config.ini、.doorstop_version、BepInEx 文件夹。
注意:BepInEx\config\_savebackup 里存着读档前的自动备份,卸载前想留就先拷出来。
另外如果你的游戏根目录里还有**别的** BepInEx 插件,卸载会把整个 BepInEx 文件夹删掉,请先备份。

== 卡在杀毒软件? ==
这个包没有任何恶意代码:不改游戏原文件、不写注册表、不联网、不常驻。但两件事会让杀软起疑:
  1. 它没买数字签名(签名证书是收费的);
  2. 它要往游戏目录放一个 winhttp.dll —— BepInEx 的注入机制就是靠这个,而这恰好是木马也常用的手法。
所以被杀软拦的时候:
  · **推荐改用「ICEY V4 便携版.zip」**:解压出来手动复制文件,全程没有任何程序被"执行",最不容易被拦;
  · 用图形安装器的话,Windows 提示「已保护你的电脑」时点「更多信息」→「仍要运行」;
  · 不放心可以拿发布页给出的 SHA-256 自己核对文件。
请**不要**为此关闭杀毒软件或加白名单;真要上报误报,各家杀软的"误报申诉"页面都是免费的。

== 已知注意 ==
1. 第一次启动如果黑屏,说明 BepInEx 入口点没生效:打开 BepInEx\config\BepInEx.cfg,
   确认 [Preloader.Entrypoint] 段是 Assembly = UnityEngine.dll / Type = MonoBehaviour / Method = .cctor(本包已预设好)。
2. 面板打开时会暂停游戏,并给主相机挂一个模糊滤镜做毛玻璃 —— 关面板会自动摘掉。
3. 面板里的"手动读档"会先把存档目录自动备份到 BepInEx\config\_savebackup\ 再读。
4. 刀光(攻击特效)目前**去不掉**,已搁置;相关开关默认关闭。
5. 第一人称视角**还没做**,可行性调研见上级目录的「第一人称调研.md」。
6. **F2 那个官方调试面板**:理论上可行(静态证据充分),但**写这份说明时还没在实机按过一次**。
   如果你按 F2 没反应,请看 BepInEx\LogOutput.log 里搜 [dbg] 的行,把它发回给作者。
