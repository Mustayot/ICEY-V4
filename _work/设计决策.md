## 已核实的技术事实(带证据)

### 毛玻璃
- 抓屏管线齐全:`ReadPixels`(UnityEngine.il 11994)、`GetPixels32`(11822)、`SetPixels32`(11553)、`RenderTexture.GetTemporary`(13046)、`Graphics.Blit`(8161)、`Camera.targetTexture`(46965)、`GUI.DrawTextureWithTexCoords`(129535)
- 游戏自带 **13 个 `CameraFilterPack/Blur_*` shader**,全名在 `globalgamemanagers` 里,**不需要新 shader 资源**
- **游戏自己就在剧情 E1 / E19 里用** `Create<CameraFilterPack_Blur_Movie>()` → DOTween 调静态 `ChangeRadius` → `Remove<>()`
- `Blur_Movie` 默认 `Radius=150 / Factor=200 / FastFilter=2`;`GaussianBlur.Size=10` Range(1,16)
- ⚠️ **坑**:所有滤镜的 `Update()` 每帧把**静态** `Change*` 写回实例字段 → **直接改实例字段会被覆盖**,必须改静态字段;而静态字段是全局的,可能和游戏剧情演出抢
- ⚠️ `AddComponent` 那一帧滤镜还没生效(`Start()` 未跑,`SCShader` 为 null → 直通);想保险就手动补 `f.SCShader = Shader.Find(...)`
- ⚠️ `CameraFilterUtils.Create` 不查重;混用 `Create` 与手写 `AddComponent/Destroy` 会让它的静态记账表失真 → **只走一套**
- `R.PauseGame()` 确实把 `Time.timeScale` 设为 0(先压栈保存旧值);渲染与 OnGUI 是否继续属**引擎语义**(非 IL 证据),强反证是暂停菜单本身是 NGUI —— 渲染停了它不会显示
- 糊的是 `Camera.main`,**游戏自己的 NGUI 界面(HUD/暂停菜单)不会被糊**,面板也不会

### 游戏机制
- **`isDebugBuild = true`** —— 零售版是开发版,游戏内按 ` 键直接开官方调试面板(11 个窗口)
- `currentHP` setter 有 `Mathf.Clamp(0, maxHP)`,想超上限必须先改 `maxHP`
- **无敌不在 `PlayerAttribute` 里** —— 是 `PlayerHurtAbility.Invincible`(public bool)
- `GameData.Difficulty` 是 **int32 字段**(0易/1普/2难/3地狱),不是枚举
- 场景名表从 `globalgamemanagers` 提取:**167 个场景**,主角关卡形如 `C1L1S1`,血宫是 `palace0~7`
- `sqlite.db` 是**唯一**运行时读 StreamingAssets 的文件
- `StreamingAssets\Movies\ps4\*.mp4` 在 PC 上是**死文件**(真视频在 `resources.assets`,Theora)
- 强化效果值不在数据表里(全 0),在代码里

### 工具链
- net35 插件编译:游戏自带 `mscorlib.dll` + Framework 4.8.1 的 `csc.exe` **`/noconfig /nostdlib /codepage:65001`**,外加 `/reference:Assembly-CSharp.dll`(漏了它 `R` 和 `WorldTime` 都找不到)
- BepInEx 5.4.23.5 + **Doorstop 4.5.0**;Unity 5.4 必须把 `BepInEx.cfg` 的 `[Preloader.Entrypoint]` 改成 `Assembly = UnityEngine.dll / Type = MonoBehaviour / Method = .cctor`,否则游戏脚本全部反序列化失败(989 次布局错位 + 2176 次脚本丢失 → 黑屏)
- ⚠️ **插件 `Awake()` 里绝对不能碰 Unity API**:早期创建 `Font` 会导致 `0xc0000005` 崩溃(已踩过)。字体与贴图一律延迟到第一次 `OnGUI`
